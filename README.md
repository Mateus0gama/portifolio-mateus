# 👨‍💻 Meu Portfólio Pessoal

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi construído para consolidar e colocar em prática todos os conhecimentos adquiridos do **Módulo 1 ao Módulo 5** do curso de HTML5 e CSS3 do professor Gustavo Guanabara (Curso em Vídeo).

Como estudante de Sistemas de Informação no IFS, este projeto marca um passo importante na construção da minha base como desenvolvedor full-stack, dominando a interface e o front-end antes de avançar para lógicas complexas de back-end.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout e responsividade[cite: 4, 5].
- **JavaScript:** Interatividade da página, manipulação do DOM e armazenamento de dados[cite: 6].

## ✨ Funcionalidades e Conceitos Aplicados

Durante o desenvolvimento deste portfólio, apliquei diversos conceitos modernos de desenvolvimento web:

- **HTML Semântico:** Uso apropriado de tags como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, e `<footer>` para melhor acessibilidade e SEO.
- **Tema Claro/Escuro (Dark Mode):** Implementação de um botão de alternância de tema utilizando JavaScript. O estado do tema é salvo no `localStorage` do navegador, garantindo que a preferência do usuário seja lembrada nos próximos acessos[cite: 6].
- **Variáveis CSS:** Uso de Custom Properties (`:root`) para gerenciar as paletas de cores do tema claro e escuro de forma escalável e organizada[cite: 4].
- **Layout Moderno:** Construção da estrutura visual utilizando **CSS Grid** para o esqueleto principal e **Flexbox** para o alinhamento de componentes internos (como cards de projetos e barras de skills)[cite: 4].
- **Responsividade:** Uso de **Media Queries** (Mobile First / Desktop First) para adaptar o layout de uma coluna única em dispositivos móveis para múltiplas colunas em telas a partir de 768px[cite: 5].
- **Rolagem Suave (Smooth Scroll):** Código em JavaScript que intercepta os cliques no menu de navegação e desliza a tela suavemente até a seção desejada, descontando a altura do cabeçalho fixo (`sticky`)[cite: 6, 4].
- **Interatividade com HTML Puro:** Uso das tags `<details>` e `<summary>` na seção de projetos para criar seções expansíveis de "Saiba mais..." sem a necessidade de bibliotecas externas.
