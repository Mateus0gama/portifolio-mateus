Tela de Login Responsiva

Este projeto representa um passo prático na consolidação dos meus conhecimentos em front-end, focando na estruturação semântica e estilização com HTML5 e CSS3. O objetivo foi desenvolver uma interface de autenticação moderna e totalmente responsiva, garantindo uma navegação fluida em qualquer dispositivo.

Saiba mais...

Para alcançar esse resultado, apliquei Media Queries para adaptar o layout e o comportamento visual entre telas de celulares, tablets e desktops. Também implementei o uso de variáveis nativas no CSS para gerenciar a paleta de cores baseada em tons de verde e lilás, o que torna a manutenção do código muito mais eficiente e escalável.


Como estudante de Sistemas de Informação construindo uma base sólida para atuar como desenvolvedor full-stack, utilizo desafios práticos como este para dominar os fundamentos da web e da interface de usuário antes de integrar o lado do cliente com lógicas complexas de back-end.
